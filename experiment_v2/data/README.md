# Данные и происхождение

Исходный архив WEPAStacks хранится в соседней замороженной серии: `../../series_py312/data/raw/wepastacks_orders.json.gz`. Нормализованная таблица - `../../series_py312/data/normalized/source.parquet`. Функции sample/campaign работают с этой таблицей при каждом повторе V2. Оба направления потока, включая внешние заявки освобождения мест, одинаковы внутри пары/тройки. Их совместная контрольная сумма записана в input_hash.

Источник - репозиторий malerinc/slapstack, commit da6280a8f8be1010eae64264c69a90258a288173, файл use_cases/wepastacks/2_orders.json. Аудит V1 содержит 411 830 строк и разделение 56/13/17 полных суток. Профили прорежены раздельно по направлениям, 20 модельных SKU сохранены. Сведения об оборудовании, качестве, геометрии, специальных партиях, датчиках и затратах заданы как сценарные. Статус и хеши исходных файлов перечислены в манифестах V1.

models.joblib содержит коэффициенты шести отдельных зональных моделей, обученных по двум группам для каждой нагрузки. В holdout.csv записаны отложенные ошибки F0/F1 по группам и периодам. При построении признаков учитываются только прошлые закрытые интервалы и время суток. При диспетчеризации доступны доставленные к моменту решения события. Режим IDEAL используется только в диагностической абляции.
