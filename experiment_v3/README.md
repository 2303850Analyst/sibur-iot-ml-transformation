# WMS V3

Рабочее состояние - PARTIAL. Исходный пакет пользователя находится в design/. Его контрольные суммы и повторная генерация всех строк проверены. Результаты технической разработки находятся в results/. Основные манифесты остаются неизменяемыми.

## Воспроизведение

На этом хосте используется PowerShell 7, Docker и Python из соседней папки .venv. В каталог родительского проекта уже помещена локальная конфигурация доступа. Сценарии V3 используют отдельные базу, тома, контейнеры и порты. ТСД доступен на локальном порту 18079 по пути /v3/tsd. Стенд нагрузочного пилота слушает порт 18080. Mosquitto слушает порт 18893.

Из experiment_v3:

```powershell
pwsh -File live/setup.ps1
pwsh -File run_all.ps1 preflight
pwsh -File run_all.ps1 functional
pwsh -File run_all.ps1 pilot
pwsh -File run_all.ps1 live-pilot
pwsh -File run_all.ps1 audit
pwsh -File run_all.ps1 report
```

Команда `pwsh -File run_all.ps1 resume` продолжает недостающие технические прогоны, запускает контрольные проверки и обновляет checkpoint. Пока квалификация основного исполнителя открыта, команда завершится с кодом 2 и напечатает оставшиеся работы. Чтобы повторить технический пилот Odoo на свежей копии шаблона, используйте live-pilot. Эта команда сохраняет предыдущую базу пилота и занимает около восьми минут.

## Состояние измерений

В report/RESULTS_RU.md и report/UNIFIED_COMPARISON.xlsx приведены фактические данные пилота. Труд, техника и время поступления имеют разные единицы. Порог основного результата - индивидуальные 72 часа. Для программного контура единица - секунда работы стенда. В results/coverage перечислены все невыполненные основные задания с идентификаторами.

Проверка восьми контрольных мутаций работает по событиям. Дополнительный обработчик audit_database.py выполняет чтение проводок и фактических остатков Odoo. Область каждого аудита указана рядом с его результатом.

Файл design/V3_PROTOCOL.json закрепляет дизайн. Для основной серии потребуется отдельная фиксация версии исполнителя после устранения перечисленных в report/COMPLETENESS.md расхождений. Время лабораторного пилота учитывается отдельно от модельных минут. Воспроизведение основного эксперимента, статистика и экономическая интерпретация остаются незавершёнными.
