# Склад ПСВ

Для описаний и расчётов по приёмке ПСВ применять [правила сравнения As-is и To-be](writing/Финальная%20оценка%20Ex/Приёмка%20ПСВ%20-%20правила%20сравнения%20As-is%20и%20To-be.md). В документе заданы два конкретных процесса по P01-P25, ручная приёмка и цифровая приёмка с двумя Zhengdu. Для каждой операции указаны исполнитель, длительность и единица измерения. При изменении исходных условий по запросу пользователя обновить соответствующую версию правил и указать, к какой версии относятся результаты.
